# ❓ Open Question Database

A community question bank (inspired by Open Trivia DB) where users contribute, browse and manage trivia questions. Built with **React** and **Firebase**.

**▶ Live demo: [openquestionsadddatabase.netlify.app](https://openquestionsadddatabase.netlify.app/)**

## Features
- 🔐 Register, log in and change password (Firebase Auth)
- ➕ Add **multiple-choice** or **true/false** questions with category and difficulty
- 📚 Browse submitted questions
- ✏️ Edit your unverified questions from your profile

## Tech stack
React · React Router · React Bootstrap · React Spring · Firebase Auth · Cloud Firestore · Netlify

## Run locally
```bash
git clone https://github.com/saravanan-22/open-question-database.git
cd open-question-database
npm install
npm start
```
